# Expansion cards #57-141 overview

`expansion-cards-57-141-overview.pdf` - all 85 cards, fronts on top and backs below, five cards per page (low-res review sheet).

Sources of truth for implementing a card:
- Final print faces and 2-page PDF: `expansion/cards/<nnn>_<id>/front.png`, `back.png`, `<id>_<n>.pdf`
- Herb-shaped record: `expansion/cards/<nnn>_<id>/profile-draft.json`
- Owner text edits (healing traits etc.): `expansion/text-overrides.json`
- Per-card input provenance: `expansion/cards/<nnn>_<id>/approved_final/provenance.json`

Cards are drafts and are not in CATALOGUE; promotion is a separate reviewed step.
