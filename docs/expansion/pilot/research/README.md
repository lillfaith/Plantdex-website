# Pilot botanical research (PROPOSALS ONLY)

Five cards: #57 Eupatorium perfoliatum, #60 Rudbeckia hirta, #67 Rumex crispus, #68 Plantago lanceolata, #80 Trifolium repens.
Each has `<herb-id>.md` (readable) and `<herb-id>.json` (same content, machine-readable, every claim carries source ids).
Retrieval date for all sources: 2026-11-25. Nothing here is final wording, nothing is imported or published, and no code, art or the draft branch was touched.

## Method limits (read first)
- The sandbox proxy blocked POWO, WCVP, GBIF, PubMed, USDA, Wikidata, iNaturalist, IPNI, WFO, Crossref and others. Only Wikipedia (rate-limited) and a USDA redirect answered.
- Everything was read through the Exa search/fetch tool, which returns excerpts. Most journal articles were read as abstracts only. WCVP/POWO checks are recorded as NOT FOUND.
- GBIF matches were fetched through that reader, not directly. GBIF is an aggregator, not a nomenclatural authority.
- Status words: SUPPORTED / TRADITIONAL_USE_ONLY / UNSUPPORTED (NOT FOUND or PRECLINICAL given in the note).
